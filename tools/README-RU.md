## auth-client

Шаблон, с которого начинается каждое новое приложение.

## Что внутри

- **Готовая структура** — все приложения разные по сути, но одинаковые по устройству
- **Связь с auth-center уже настроена** — достаточно выпустить новый секрет, и приложение сразу в экосистеме
- **Два региона** — `ru` и `com`: свой домен и язык интерфейса, деплой в оба одной кнопкой
- **Вход в соседние приложения без повторной авторизации** — вместе с именем пользователя
- **Единый вид** — страница входа, меню пользователя и фон такие же, как во всех приложениях
- **Ночной бэкап базы** — ставится автоматически при деплое
