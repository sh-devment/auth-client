## auth-client

The template every new app starts from.

## What's inside

- **Ready-made structure** — the apps differ in purpose, but they're all built the same way
- **Already wired to auth-center** — just issue a new secret and the app is part of the ecosystem
- **Two regions** — `ru` and `com`: each with its own domain and UI language, deployed to both in one click
- **Open the other apps without signing in again** — the user's name comes along
- **One look** — the login page, the user menu and the background match every other app
- **Nightly database backup** — set up automatically on deploy
